Ayuda del componente Navegador

Guía práctica para instalar, adaptar y usar el CRUD en Windows Forms.

El Navegador es un UserControl reutilizable. Se coloca dentro de un formulario normal, recibe el nombre de una tabla y los identificadores de Seguridad, lee el esquema de la base de datos y construye la cuadrícula y los campos para insertar, consultar, modificar y eliminar.

Ruta recomendada

  1. Revise los requisitos y ajuste las dos rutas del archivo build_navegador.bat.
  2. Configure en Windows el DSN ODBC de 64 bits y seleccione en él la base de datos.
  3. Ejecute el archivo de compilación y confirme que no haya errores en el resumen.
  4. Agregue CapaVista_Navegador.dll a la caja de herramientas y arrastre el control al formulario.
  5. Configure tabla, módulo y aplicación con una sola llamada.
  6. Inicie sesión desde Seguridad y abra el formulario integrado.

Configuración mínima

public FrmMiMantenimiento()
{
    InitializeComponent();
    navegador1.NavegadorMetConfigurar("tblempleado", 4, 5);
}

El formulario no hereda de una clase especial. navegador1 es la instancia colocada desde el diseñador.

Antes de empezar

No coloque contraseñas en el código del Navegador. El componente usa el DSN y la sesión del componente Seguridad. Los permisos de Ingresar, Modificar, Eliminar e Imprimir se calculan con el módulo y la aplicación configurados.

Si solo necesita resolver un fallo, vaya a Diagnóstico y errores frecuentes.
