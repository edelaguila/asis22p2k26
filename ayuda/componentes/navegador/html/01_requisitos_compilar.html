Requisitos y compilación

Prepare el equipo y compile las dependencias en el orden correcto.

Requisitos

  • Windows con Visual Studio 2022 y las herramientas de compilación de .NET Framework.
  • .NET Framework 4.8 Developer Pack.
  • Motor MySQL o MariaDB en ejecución y las bases de datos requeridas por Seguridad, Consultas y el mantenimiento.
  • Controlador MySQL ODBC 8.x de 64 bits, porque los proyectos Debug del Navegador se compilan para x64.
  • Permiso para crear y probar un DSN de sistema o de usuario.

Ajustar el archivo de compilación

Archivo exacto que puede editarcodigo\componentes\navegador\build_navegador.batSección dentro del archivoRUTAS FIJAS - variables MSBUILD_PATH y COMP

Abra el archivo y revise:

VariableQué debe contener
MSBUILD_PATHRuta de MSBuild.exe. Si usa Professional o Enterprise, cambie “Community” por su edición.
COMPRuta absoluta de codigo\componentes en su copia local.
set "MSBUILD_PATH=C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe"
set "COMP=C:\proyectoasis22k26-Navegador\codigo\componentes"
No cambie las rutas internas de los proyectos salvo que la estructura de carpetas haya cambiado.

Compilar

  1. Cierre ejecutables que puedan mantener DLL bloqueadas.
  2. Ejecute build_navegador.bat.
  3. El archivo restaura y recompila Consultas, Seguridad, Navegador y los ejecutables en orden.
  4. Revise el resumen: Errores debe ser 0 y las salidas deben aparecer como [OK].
  5. Pulse S para salir o R para recompilar.

El detalle queda en codigo\componentes\navegador\logs\build_navegador_log.txt. Corrija el primer error; los siguientes suelen ser consecuencias.
