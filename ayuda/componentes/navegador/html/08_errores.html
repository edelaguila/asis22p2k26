Diagnóstico y errores frecuentes

Qué revisar, en orden, antes de modificar código.

InicioCompilarConexiónIntegrarConfigurarEjecutarCRUDBotonesErrores

Orden de diagnóstico

  1. Motor de base de datos iniciado.
  2. DSN ODBC de 64 bits existente y prueba exitosa.
  3. DSN apuntando a la base correcta.
  4. Nombre de tabla exacto en NavegadorMetConfigurar.
  5. Compilación sin errores y DLL actualizada.
  6. Sesión de Seguridad activa.
  7. Módulo, aplicación y permisos asignados.

Problemas comunes

SíntomaCausa probableSolución
“Data source name not found”.DSN ausente, distinto o de 32 bits.Crear EmbutidosS.A en ODBC de 64 bits o cambiar ClsConexion.cs.
Error al consultar o estructura vacía.Base, tabla o privilegios incorrectos.Revisar el DSN, el primer parámetro y permisos SQL.
El control no aparece.DLL incorrecta, sin compilar o plataforma incompatible.Recompilar, elegir CapaVista_Navegador.dll y usar x64.
Faltan DLL al ejecutar.Dependencias de Consultas o Seguridad ausentes.Usar referencias de proyecto o la salida generada por el archivo de compilación.
Botones deshabilitados.Sin sesión, IDs incorrectos o sin permisos.Entrar desde Seguridad y revisar módulo, aplicación, perfil y asignaciones.
No detecta la llave primaria.No existe PK o el controlador no expone metadatos.Definir la PK o seleccionar columnas cuando se solicite.
No carga una llave foránea.Relación ausente o tabla inaccesible.Revisar la FK, privilegios y datos relacionados.
Error por tipo o longitud.Valor incompatible con el esquema.Corregir números, fechas, obligatorios o longitud.
No se puede eliminar.Otro registro lo referencia.Revisar datos dependientes antes de eliminar.
Imprimir no genera reporte.Función no integrada.La integración con Reporteador sigue pendiente.

Si la compilación falla

Abra codigo\componentes\navegador\logs\build_navegador_log.txt, localice el primer proyecto con [ERROR] y corrija su primer mensaje. Revise especialmente MSBUILD_PATH y COMP.
