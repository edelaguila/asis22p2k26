Introduccion

En esta ayuda se explica el funcionamiento del boton Ver Reporte del modulo Reporteador. Este boton permite visualizar el reporte que se desee del listado de reportes..

4

Para que sirve

El boton Ver Reporte permite visulizar el reporte del registro seleccionado. Al usarlo, la pantalla carga el reporte y su informacion en el ReportViewer.

5

Como se utiliza

Localizar el boton

  • Abrimos la pantalla donde aparece el listado de reportes y localizamos el boton con el icono de Ver reporte .

Seleccionar un registro

  • Hacemos clic una vez sobre el registro que deseamos visualizar.

Hacer clic en Ver Reporte

  • Hacemos clic una vez sobre el boton Ver Reporte.
6

Despliegue del reporte

  • Como podemos observar, el sistema despliega el reporte seleccionado en el ReportViewer, mostrando su toda la informacion.
7

Situaciones a tener en cuenta

  • Si no se entrega ningun idAplicacion, el sistema desplegara un mensaje de error.
  • Si no se entrega una lista de objetos, el sistema desplegara el ReportViewer sin contenido..
