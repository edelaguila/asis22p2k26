Bienvenida

Bienvenido a la ayuda general del módulo Reporteador. Este manual reúne las funciones principales disponibles en la pantalla de reportes y explica de forma sencilla cómo utilizarlas.

Desde este módulo es posible seleccionar la ruta de un archivo de reporte, registrar nuevos reportes, modificar registros existentes, deshabilitarlos, limpiar los campos del formulario, imprimir reportes, buscar información mediante filtros y refrescar la tabla de resultados.

4

Vista general del Reporteador

La pantalla principal se divide en tres áreas. En la parte superior se encuentran los campos Ruta del reporte y Nombre del reporte. Debajo se ubican las acciones principales del módulo, y en la parte inferior se encuentra el área de búsqueda junto con la tabla de reportes registrados.

  • Ruta del reporte: permite seleccionar el archivo del reporte.
  • Nombre del reporte: identifica el reporte dentro del sistema.
  • Tabla: muestra número, nombre, ruta y fecha del reporte.
  • Área de búsqueda: permite filtrar por nombre, fecha o ambos criterios.
5

Seleccionar ruta del reporte

El botón Ruta del reporte abre el explorador de archivos de Windows para seleccionar un archivo de reporte con extensión .rdlc.

Confirmar la selección

Una vez seleccionado el archivo, se presiona Abrir. El sistema carga automáticamente la ubicación del archivo en el campo Ruta del reporte.

6

Guardar un reporte

Para registrar un nuevo reporte deben estar completos los campos Ruta del reporte y Nombre del reporte.

Al presionar Guardar, el sistema registra la información y muestra un mensaje indicando que la operación se realizó correctamente.

7

Modificar un reporte

Para modificar un reporte primero se selecciona su fila en la tabla y luego se presiona el botón Modificar. Los datos del registro seleccionado se cargan nuevamente en los campos del formulario.

Después de cambiar el nombre o la ruta, se utiliza Guardar para actualizar el registro. El sistema refresca la tabla para mostrar los nuevos datos.

8

Eliminar o deshabilitar un reporte

La acción Eliminar se utiliza para deshabilitar un reporte seleccionado. El registro no se borra físicamente de la base de datos; queda marcado como inactivo para conservar la información registrada.

Antes de completar la acción, el sistema solicita confirmación. Si se confirma, el reporte queda deshabilitado y deja de estar disponible para las operaciones que correspondan.

9

Limpiar reporte

El botón Limpiar Reporte permite limpiar los datos que se encuentran actualmente en los campos del formulario y dejar la pantalla lista para realizar una nueva operación.

Esta acción es útil cuando se desea cancelar la información que se estaba ingresando o comenzar el registro de un nuevo reporte sin conservar datos anteriores en los campos.

10

Imprimir reporte

El botón Imprimir trabaja con el reporte seleccionado en la tabla. El sistema obtiene la ruta asociada al registro y utiliza el componente de impresión para enviar el archivo correspondiente a la impresión.

Para utilizar esta función debe existir un reporte seleccionado y una ruta válida asociada al archivo del reporte.

11

Buscar y aplicar filtros

El Reporteador permite buscar registros utilizando el nombre del reporte, la fecha del reporte o ambos criterios al mismo tiempo.

Filtro por nombre

Filtro por fecha

Después de ingresar los criterios se presiona Aplicar Filtro y la tabla muestra únicamente los registros que cumplen las condiciones seleccionadas.

12

Refrescar la información

El botón Refrescar vuelve a cargar la información de la tabla para mostrar el estado actual de los reportes.

Puede utilizarse después de realizar cambios o búsquedas para recuperar la vista actualizada de los registros.
